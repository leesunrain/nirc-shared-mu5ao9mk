OneClick App Deployer v1.6.6 FIX

현재 버전: v1.6.6

핵심 수정
- 자동판정(provider=detect)이 실행되기 전에 공통 token 검사에서 차단되던 버그 수정
- GitHub/Vercel 개별 연결 확인은 기존 방식 그대로 유지
- detect는 githubToken + vercelToken을 사용하도록 정상 통과
- 이름 식별/안전장치/배포 로직은 v1.6.5 그대로 유지

원인
기존 코드:
  if(!token) return "토큰이 없습니다."

자동판정 요청:
  provider: detect
  githubToken: ...
  vercelToken: ...
  (공통 token 필드는 없음)

따라서 detect 분기까지 도달하지 못하고 항상 종료되고 있었습니다.
